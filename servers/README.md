Сюда клади клиентские конфиги AmneziaWG, по одному на сервер:

```
awg-1-main.conf
awg-2-reserve.conf
awg-3-...conf
```

Имя должно начинаться с `awg-`, порядок по алфавиту: первый основной, остальные запасные. Конфиги в git не попадают

Под каждый роутер лучше выпустить отдельного пира, а не брать конфиг с телефона или компа: один и тот же ключ на двух устройствах сразу работать не будет
